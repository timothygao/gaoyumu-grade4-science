# 高语牧 · 四上科学《声音的强弱与高低区分》知识清单核对

来源：用户于 2026-11-22 上传的单页照片 `IMG_6005(1).jpg`。文件以照片可辨认的实验结果及术语为出题依据。与旧《空气》及《呼吸与消化》题库分开。

## 原清单5部分

1. 强弱高低口诀：声音强弱与振动幅度有关，大小用力控制；声音高低与振动快慢有关，由物体自身条件决定（短的物体通常音高）。
2. 钢尺强弱对照：伸出桌面长度**相同**，用力拨→幅度大→声音强；轻轻拨→幅度小→声音弱。因果：用力大小→振动幅度→声音强弱。
3. 钢尺高低对照：改变伸出桌面的长度；伸出长→振动慢→声音低；伸出短→振动快→声音高。
4. 三支装水试管：①水量最少、②居中、③最多。往管口吹气时空气柱振动，声音最低的是①；敲击试管时试管和水振动，声音最低的是③。注意同一组试管的两种发声方式不可混为一谈。
5. 往暖水瓶倒水：水位升高→上方空气柱变短→空气柱振动更快→声音更高。

### 照片内部疑点（没有静默修改原图）
第3部分表格写“振动快慢／声音高低”，但底部“我的发现”误写成“物体的长短→物体振动的幅度→声音的强弱”，与本部分观察数据冲突。本新卷根据**本部分实验表格**出题，参考答案解释振动快慢→音高，并在页面向家长提示原清单不一致。
